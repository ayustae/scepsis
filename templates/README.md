# Scepsis - Templates

Default Markdown templates used by the Scepsis framework. `chreos` renders these when creating new items; they also document the suggested structure for anyone writing the files by hand.

## Contents

| **Name** | **Purpose** |
| --- | --- |
| [`PROJECT.md`](PROJECT.md) | A project: heading, summary and `## Description` |
| [`TASK.md`](TASK.md) | A task: heading, summary, `## Description`, `## Acceptance criteria`, `## References` and `## Notes` |
| [`DECISION.md`](DECISION.md) | A decision: heading, summary and `## Description` (context, options, recommendation and outcome) |
